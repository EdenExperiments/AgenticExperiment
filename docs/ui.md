# UI

LifeQuest themes: Minimal, Retro, Modern via `data-theme` on `<html>`. Stylish is `data-mode="stylish"` on top — atmosphere only, not new layout.

NutriLog and MindTrack use product themes (`nutri-saas`, `mental-calm`), not the LifeQuest switcher.

Tokens live in `packages/ui/tokens/`. Use `var(--color-*)`. Same behaviour in every LifeQuest theme.

Read the CSS and components.
